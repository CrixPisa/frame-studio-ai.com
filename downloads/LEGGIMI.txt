# Downloads pubblici FrameAI

Generati automaticamente da plugins\publish-plugin.ps1 (esegui da PowerShell
nella cartella FrameAI dopo ogni modifica ai plugin):

  .\plugins\publish-plugin.ps1

File presenti:
  FrameAI-Studio-Premiere.ccx    -- pacchetto dev (non firmato Adobe)
  FrameAI-Studio-Photoshop.ccx   -- pacchetto dev (non firmato Adobe)
  FrameAI-Studio-AE.zip          -- pacchetto dev (non firmato Adobe, richiede debug mode)
  FrameAI-Nuke.zip
  FrameAI-Resolve.zip
  FrameAI-VegasPro.zip
  FrameAI-Blender.zip
  FrameAI-MCP-Claude.zip

Per un vero .zxp firmato Adobe (invece del pacchetto dev, che funziona ma
richiede installazione manuale in debug mode -- vedi README dentro lo zip):

  1. Scarica ZXPSignCmd (Adobe, gratuito) e crea un certificato self-signed
     (istruzioni in plugins\aftereffects-cep\README.md)
  2. .\plugins\publish-plugin.ps1 -ZxpPath "percorso\al\file_firmato.zxp"

Per pacchetti Premiere/Photoshop firmati Adobe (invece del pacchetto dev,
che funziona ma richiede installazione manuale via UXP Developer Tool):

  1. Apri UXP Developer Tool -> seleziona il plugin -> "Package" -> ottieni il .ccx
  2. .\plugins\publish-plugin.ps1 -CcxPath "percorso\premiere.ccx" -PhotoshopCcxPath "percorso\photoshop.ccx"

La pagina di download e' /plugin (src/pages/PluginPage.tsx). Dopo aver
rigenerato i file, fai build + deploy del sito.
